# MXW01 Web Print

Веб-страница для отправки текста, изображений и PDF на мини-принтер MXW01 через Bluetooth Low Energy (BLE), без отдельного приложения Fun Print.

## Возможности

- Подключение к принтеру MXW01 через Web Bluetooth.
- Печать введённого текста.
- Печать изображений PNG и JPG.
- Печать PDF-документов: страницы отправляются последовательно, в порядке документа.
- Предпросмотр перед печатью.
- Настройка размера текста и порога чёрного цвета.
- Журнал BLE-обмена и состояния задания.

## Что потребуется

- Google Chrome с поддержкой Web Bluetooth.
- Принтер MXW01 с заряженным аккумулятором и установленной термобумагой.
- Интернет при открытии страницы, если требуется обработка PDF: библиотека PDF.js загружается с CDN.

> Обычное открытие HTML как локального `file://` может ограничивать работу Web Bluetooth в зависимости от версии Android и Chrome. Если кнопка подключения не работает, откройте страницу через HTTPS-хостинг или локальный веб-сервер, доступный телефону.

## Запуск

1. Распакуйте ZIP-архив.
2. Откройте `mxw01_web_print.html` в Chrome на Android из безопасного контекста (предпочтительно HTTPS).
3. Включите принтер и убедитесь, что он находится рядом с телефоном.
4. Нажмите **«Подключить MXW01»**.
5. В системном окне Bluetooth выберите устройство **MXW01**.
6. Дождитесь сообщения **«Подключено к MXW01»**.

Не подключайте принтер одновременно из Fun Print или другого приложения: другое приложение может занять BLE-соединение.

## Печать текста

1. В поле **«Текст»** введите содержимое.
2. Установите размер текста.
3. Настройте **«Плотность (порог)»**, если отпечаток слишком светлый или слишком тёмный.
4. Нажмите **«Обновить предпросмотр»**.
5. Проверьте изображение на экране.
6. Нажмите **«ПЕЧАТАТЬ»**.

Размер текста в интерфейсе ограничен диапазоном 12–48. Перенос длинных строк выполняется автоматически.

## Печать изображения

1. В разделе **«Изображение (PNG/JPG)»** выберите файл.
2. Проверьте предпросмотр.
3. При необходимости измените порог плотности.
4. Нажмите **«ПЕЧАТАТЬ»**.

Изображение масштабируется по ширине печати 384 точки с сохранением пропорций.

## Печать PDF

1. В разделе **«Или документ PDF»** выберите PDF-файл.
2. Дождитесь сообщения о загрузке документа и количестве страниц.
3. На экране показывается первая страница.
4. Нажмите **«ПЕЧАТАТЬ»** — страницы будут отправляться последовательно.

Ограничения PDF:
- Максимум 100 страниц на один документ.
- Страница масштабируется по ширине 384 точки.
- Высота страницы ограничивается 3000 точками.
- Для обработки PDF требуется загрузка PDF.js с CDN; сам PDF-файл передаётся библиотеке в браузере и не загружается на сервер проекта.

## Параметры растра

- Ширина печати: 384 точки (примерно 48 мм).
- Один горизонтальный ряд содержит 48 байт.
- Каждый байт кодирует 8 горизонтальных пикселей.
- В текущей рабочей версии используется порядок битов от младшего к старшему (LSB first).
- Порог бинаризации по умолчанию: 160.
- Передача данных выполняется порциями по 48 байт с небольшой задержкой между отправками.

## Журнал и диагностика

В блоке **«Журнал»** отображаются:
- состояние BLE-подключения;
- размеры холста и количество тёмных пикселей;
- число ненулевых байтов растра;
- команды и ответы принтера;
- сообщения об ошибках и завершении задания.

Если печать не удалась, сохраните или скопируйте журнал и приложите его к сообщению о проблеме. Фотография фактического отпечатка также помогает диагностике.

## Если не подключается или не печатает

**Принтер не появляется в списке**
- Проверьте питание принтера.
- Поднесите телефон ближе.
- Закройте Fun Print и другие приложения, которые могли подключиться к принтеру.
- Повторите подключение из Chrome.

**Web Bluetooth недоступен**
- Используйте Chrome на Android.
- Откройте страницу в безопасном контексте HTTPS.
- Проверьте, что Bluetooth включён и Chrome имеет необходимые разрешения.

**Отпечаток слишком светлый или тёмный**
- Измените порог плотности и выполните короткий тест.
- Убедитесь, что используется подходящая термобумага и она установлена правильной стороной.

**PDF не загружается**
- Проверьте интернет-соединение: PDF.js загружается с CDN.
- Попробуйте открыть файл в другом PDF-просмотрщике и убедитесь, что файл не повреждён.
- Уменьшите документ до 100 страниц или меньше.

**Задание прервалось**
- Не нажимайте «ПЕЧАТАТЬ» повторно, пока не проверите, не продолжает ли принтер выполнять предыдущее задание.
- Проверьте бумагу, крышку и заряд аккумулятора.
- Переподключите принтер и выполните тест на одной короткой строке.

## Важные ограничения и предупреждения

- Проект использует экспериментальный BLE-протокол для MXW01. Команды и формат обмена не подтверждены официальной документацией производителя.
- Ответ принтера о завершении задания не гарантирует идеальное качество отпечатка.
- Начинайте проверку с короткого текста или одной страницы.
- Не отправляйте длинные документы, пока короткий тест не проходит успешно.
- Не оставляйте принтер без присмотра во время печати.
- Печать может расходовать бумагу даже при неудачном результате.

## Конфиденциальность

Текст, изображения и PDF обрабатываются в браузере. PDF.js загружается с CDN. Сам файл PDF не отправляется на сервер проекта, однако страница должна получить библиотеку PDF.js из сети.
